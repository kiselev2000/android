# Seed Vault Offline — план реализации

## Цель

Собрать Android-приложение для полностью локальной генерации BIP-39 seed-фраз длиной 12 или 24 слова, ориентированное на использование с TRON/TRC-20. Приложение не должно иметь разрешение `INTERNET`, сетевых SDK, аналитики, рекламы, удалённых API, хранения seed-фразы или копирования в буфер обмена.

## Архитектура

- `app/(tabs)/index.tsx` — единственный основной экран: выбор длины, генерация, нумерованный результат, предупреждения и очистка результата.
- `lib/bip39.ts` — BIP-39 wordlist, генерация энтропии через Android CSPRNG, SHA-256 checksum, преобразование энтропии в индексы слов и проверка результата.
- `app/_layout.tsx` — минимальный локальный Expo Router layout без tRPC, API-клиента и Manus runtime-провайдеров.
- `app.config.ts` — автономная конфигурация, блокировка `android.permission.INTERNET`, удаление лишних native-плагинов и разрешений.

## Дизайн

Рассмотрены три направления: Quiet Security (0.07) — тёмный спокойный интерфейс с янтарным акцентом; Paper Ledger (0.05) — светлый бумажный журнал с моноширинной фразой; Signal Green (0.08) — строгий технический интерфейс с зелёными статусами. Выбрано **Quiet Security**.

- Движение: минималистичный secure utility с ощущением офлайн-инструмента.
- Принципы: один главный сценарий, высокая читаемость, отсутствие визуального шума, явные границы риска.
- Цвет: глубокий тёмно-синий фон, светлая типографика, янтарный accent для действия, зелёный только для подтверждения локальной проверки.
- Компоновка: вертикальная «карточка журнала» с верхним статусом OFFLINE и последовательными секциями вместо dashboard-сетки.
- Фирменные элементы: индикатор `OFFLINE`, моноширинные нумерованные слова и тонкая янтарная линия вокруг действия.
- Взаимодействие: генерация требует явного выбора длины; результат можно очистить одной кнопкой; seed никогда не копируется и не сохраняется.
- Анимация: без декоративной анимации; только короткое появление результата.
- Типографика: системный sans для интерфейса, системный monospace для слов seed-фразы.
- Голос: короткие прямые предупреждения — «Работает без сети» и «Запишите слова от руки».

## Ограничения безопасности

- Использовать системный Android CSPRNG через `expo-crypto`.
- SHA-256 checksum рассчитывать локально через `expo-crypto`.
- Не вызывать `fetch`, tRPC, axios, API, AsyncStorage, SecureStore или clipboard API.
- Проверять BIP-39 checksum до отображения результата.
- Собирать APK с блокировкой `INTERNET`; после сборки проверить Android manifest и отсутствие сетевого разрешения.
